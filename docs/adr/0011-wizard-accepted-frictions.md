# 精靈刻意保留的兩個摩擦：TMDB 閘門、建管理員的密碼只有一格

兩件看起來可以改進、但決定維持的事：

- **TMDB 憑證是精靈第 6 步的閘門**。`api.themoviedb.org` 被防火牆擋住的使用者裝不起來，是這個決定的代價，不另開「先完成精靈、探索與入庫停擺」的路。
- **建管理員的密碼只有一格**，靠「顯示密碼」（GitHub / Vercel 的慣例；二次確認欄防的是看不見的輸入錯誤）。

來源：brief §19 舊列「TMDB 連不上時的精靈」「精靈的兩個產品問題」（原文在 `docs/archive/m1.md`、`docs/archive/m2.md`）。同一列的「索引站預設全勾」後來被取代（推薦站預設不勾、先測試通過才勾，見 ADR-0013），不在此記。
