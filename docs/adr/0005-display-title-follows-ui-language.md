# 顯示用標題跟著 UI 語言走，檔名只用英文

不另做「片庫語言」設定：`zh-Hant` 介面顯示 TMDB `zh-TW` 那一輪的標題與簡介，EN 介面顯示 `en-US` 那一輪。檔名與資料夾名照舊只用英文（brief §7.5），不跟 UI 走。起因是 M1 票 15 的 critique 量到 EN 介面上海報牆、詳情頁 h1 與簡介全是中文，與「英文是一等公民」（`PRODUCT.md`）衝突。

例外：媒體庫牆上已在 Jellyfin 裡的作品顯示 Jellyfin 的名稱，不為每一部去查 TMDB——牆上多數作品 Berth 沒有快照，大媒體庫第一次載入要打上千個請求。代價是 EN 介面從牆上點進 Media 詳情時標題可能換成另一種語言。
