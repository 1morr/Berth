# Shape：探索頁 `/`（票 03）

`/impeccable shape 探索頁`，2026-09-09。使用者拍板兩個問題（海報份量、搜尋行為），其餘為本文件的判斷。
這是 shape brief，不是 direction contract：實作由票 03 的 build 進行，視覺世界沿用既有的 DESIGN.md。

## 1. 工作與讀者

- **模式：Operate。** 這一頁不是行銷頁也不是作品集——讀者是已經登入的自架者，來這裡是為了**找到那部作品**，
  然後往下一步走（票 04 的詳情頁送單）。表達力讓位給掃視速度。
- **誰來**：`admin` 與 `user` 都進得來（brief §11，探索不是管理動作）。典型情境是「我聽說有部新番／朋友推薦一部片，
  Berth 裡有沒有」。裝置以桌機為主，手機要能完成同一件事（PRODUCT.md）。
- **這一頁是 `/`**：精靈跑完、登入之後看到的第一個畫面。它取代票 10 暫時的「`/` 導向 `/health`」。
  這是有意義的：**Berth 平常應該是「找東西」的地方，不是「看它有沒有壞」的地方**。健康頁仍在導覽列上。

## 2. 成果與證據

- **主要任務**：辨認出一部作品。成功 = 使用者在牆上或搜尋結果裡指得出那一格。
- **真實資料**：TMDB `trending/{tv,movie}/week`、`{tv,movie}/popular`、`search/multi`，
  每個 feed 兩種作品交錯，實際筆數 20 + 20（TMDB 每頁 20）。搜尋結果 0–20 筆（去掉人物之後）。
- **產品專屬的真話**：卡片上的**追蹤狀態**是 Berth 才有的一欄——TMDB 不知道你追了什麼。M1 只有兩態
  （未追蹤 / 已追蹤，票 03），部分 / 完整 / 下載中要等 Job 與帳本（brief §13）。
- **法定要求**：這一頁顯示 TMDB 資料，所以頁面上要有歸屬聲明與 TMDB 標誌（brief §20.3、PRODUCT.md
  的 Evidence on Hand）。README 已有中英雙語的那句話，這是它第一次進到介面裡。

## 3. 選定方向

- **視覺權威**：既有的 DESIGN.md「泊位調度板」，不新開世界。
- **結構論點：一面貨櫃堆場的堆疊圖。** 海報塑滿格子、格與格之間是 1px 髮絲縫（`gap-px` 透出 `rule`），
  零圓角，卡片下方是一條模板字的標識帶（類型 + 年份 + 標題 + 英文標題 + 追蹤色塊）。
  海報是貨櫃的塗裝，標識帶是噴在箱體上的編號——**兩者是同一個語彙的兩層，不是圖片加說明文字**。
- **焦點時刻**：第一個 viewport 就是搜尋列 + 第一排海報。不做 hero、不做輪播、不做「精選」大圖。
- **實作後果**：這是這個世界第一次承載滿色圖像。海報自己有顏色，所以周圍的一切必須更克制——
  標識帶只用中性色，四個信號色在這一頁**一個都不出現**（見 §7）。

## 4. 範圍與邊界

- 範圍：`/` 一頁，三個 feed（趨勢、熱門、搜尋結果）與它們的載入 / 空 / 錯誤狀態。
- **不做**：詳情頁與送單（票 04）、追蹤動作本身（票 04；本票只顯示狀態）、篩選與排序、分頁與無限捲動、
  類型／語言／年份的 facet、「因為你追了 X」推薦。
- **不碰**：AppShell 的頁首、健康頁、精靈、設計 token。導覽列多一個「探索」項是唯一的外部改動。
- **反目標**：不做 Netflix 式的橫向捲動排（The Board Never Scrolls Rule 的同一個理由——被推到畫面外的
  格子等於沒顯示）；不做 hover 才出現的資訊（觸控裝置上不存在）；不做骨架屏動畫（這個世界沒有動態）。

## 5. 狀態與範圍值

| 狀態 | 樣子 |
| --- | --- |
| 載入中 | 標識帶先出現、海報格留 `well` 空位（版面不跳）。不是骨架屏動畫 |
| 正常 | 40 格（20 劇集 + 20 電影交錯），兩個 feed 共 80 格 |
| 搜尋無結果 | 一句「沒有符合的作品」+ 原查詢字串 + 「回到趨勢」 |
| 沒有海報 | 格子留 `well` 底 + 置中的 `NO ART` 模板字。**不用破圖，也不用佔位插畫** |
| 標題過長 | 顯示用標題最多兩行、英文標題一行，超出截斷（`line-clamp`）。標識帶高度固定，格子才對得齊 |
| 年份未定 | 年份那一格留 `—`，不省略——欄位消失會讓整排的基線錯開 |
| 憑證缺失 | 整頁一塊 `blocked` Notice：說明 Berth 不內建 key、連到 `/setup?berth=3`（票 02b） |
| 憑證被拒 | 同上，但說的是「TMDB 不接受這把 key」，附服務回的原文 |
| TMDB 連不上 | `blocked` Notice + 原文 + 「重試」按鈕。**這一種不連到精靈**——那裡沒有東西可修 |
| 一個 feed 壞、另一個好 | 各自顯示自己的狀態，好的那個照常畫（後端每個 feed 各自回 `problem`） |

## 6. 互動與版面

- **搜尋列**：頁面頂端、貼齊工作面寬度。**鍵入即搜，500ms 防抖，2 字以上才發**（使用者拍板）。
  有結果時搜尋結果**接管整面牆**，趨勢與熱門收起來；清空搜尋框回到原本兩個 feed。
  搜尋中不換掉上一輪結果（畫面不閃），只在搜尋列旁顯示狀態字。
- **鍵盤**：搜尋框可直接 Tab 到；每一格是一個連結（票 04 之前先是 `/media/:id` 的目標），焦點環走全域雙環。
  結果數量的變化要進 `aria-live`，否則螢幕閱讀器使用者不知道牆換了。
- **網格**：`grid-cols-2` → `sm:3` → `lg:4` → `xl:6`。格與格之間 1px 縫。**390px 窄版是兩欄**，
  一欄會讓海報大到一屏只看得到一部。
- **卡片比例**：海報固定 2:3（TMDB 的 `w342` 就是這個比例），`aspect-[2/3]` 保住版面在圖載入前就定位。
- **標識帶**：三行固定高度——① `TV` / `MOVIE` + 年份（`.label`，`ink-dim`）② 顯示用標題（`.value`，最多兩行）
  ③ 英文標題（`.value text-xs`，`ink-dim`，**與顯示用標題相同時整行不畫**）。追蹤色塊疊在海報左下角。
- **回饋**：hover / focus 時整格的邊框由 `rule` 換 `rule-strong`（線變重，不是變色，與 GhostButton 同一條規則）。

## 7. 約束與不可自行發明的決定

- **這一頁不出現四個信號色中的任何一個當作「狀態」**，除了錯誤 Notice 的 `blocked`。
  「已追蹤」用**中性色塊**（`deck` + `ink`）——依 The Role Is Not A State Rule：追蹤是一段關係，不是健康狀態。
  把它塗成 `secured`（已完成且驗過）會在 M2 真的有「完整 / 部分」時把那個字的意思用掉。
- **海報是唯一的例外圖像**。DESIGN.md 的「沒有圖示」規則不變：不引入 icon set、不加插畫、不加 emoji。
- **TMDB 歸屬**：頁尾一行 + `docs/assets/tmdb.svg`。這是條款要求，不是裝飾，不可省略。
- **i18n**：所有文案走 key，zh-Hant 與 en 並列。**作品標題本身不是文案**——它來自 TMDB，兩個標題都直接顯示。
- **無障礙**：深淺兩主題所有文字 ≥ 4.5:1（海報上的追蹤色塊也算——它疊在圖像上，所以要有自己的不透明底）。
  390px 無頁面層級橫向捲動。
- **不可發明**：feed 的順序（照 TMDB 給的，交錯合併，見 `services/discover.py` 的理由）、
  海報尺寸（`w342`）、快取時間（1 小時，plan §8.3）。

## 8. 開放但由 build 決定（已於 build 定案）

- 類型標籤：**兩個語言都用 `TV` / `MOVIE`**，而且走 `.value` 不走 `.label`。它是分類代號（與 `BTH 1`
  同一個語域），本來就是大寫，套 `.label` 只是多一層會說謊的 `text-transform`（The Machine String Rule）。
- 「已追蹤」色塊：**放標識帶上，不壓在海報上**。實跑量到的：色塊疊在圖像上時，它讀不讀得出來取決於
  那張海報那一角剛好是什麼顏色——`deck` 在亮色主題是近白，壓在深色海報上很清楚；深色主題它是中灰，
  壓在同樣深色的海報上幾乎消失。標識帶的底是 `well`，兩個主題都是設計系統保證得了的一組值
  （實測 11.95:1）。這條推翻本文件 §3 原本傾向的「疊在海報左下角」。
- 網格的線：**每一格自己的 `border-2`**，不是把整塊網格塗成 `rule` 再用 `gap-px` 透出來。泊位板那樣做
  是因為它永遠四格滿的；這面牆的格數由 TMDB 決定，塗底的話只搜到一部作品時整排空欄會變成一塊灰板子
  （實跑第一輪就是這個樣子）。
- **卡片這一票不是連結**，推翻 §6 的「每一格是一個連結」與它的 hover / focus 規則。`/media/:id` 要到
  票 04 才存在，而一個點下去沒反應的格子比一個不能點的格子更糟。票 04 接手時整格包成連結，
  hover / focus 是邊框由 `rule` 換 `rule-strong`。
- **兩個 feed 拿不到 TMDB 的理由相同時，整頁只說一次**（§5 寫的「整頁一塊 Notice」）。後端仍是逐個
  feed 各回自己的 `problem`——那是「一個垮掉不影響另一個」要的東西——去重發生在頁面這一層。
