# Shape：側面板（M5 票 12）

模式 **Operate**；全在既有的「泊位調度板」世界裡（DESIGN.md），新增的只有「對話紀錄」這一種排法，元件全部沿用。使用者 2026-10-27 選定三題（都是建議的那一個）：桌面並排、頁首一顆鍵且換頁不關、這張票不送頁面脈絡。

## 誰、何時、要做到什麼

- 登入的任何人（admin 與 user），在任何一頁上想問一句「這部為什麼還沒入庫」「我送的那筆怎麼了」。不是平常的入口：人平常只在「想找新片」與「有東西壞了」時打開 Berth，面板是後者的捷徑。
- 成功的樣子：問一句，看得到助理查了什麼（一行一個工具，展開看參數與結果），得到一個說得出原因與下一步的回答；重新載入之後對話還在。
- 用詞照 `CONTEXT.md`：介面上叫**助理**（EN *Assistant*），不叫 agent / AI 機器人。

## 與頁面的關係

- **叫出來**：頁首在導覽與登出之間一顆「助理」鍵（`NAV_BOX` 方塊、`aria-expanded`、`aria-controls`），打開時是 `NAV_BOX_ACTIVE`（重線 + `deck`，不靠顏色）。不加全域快捷鍵。
- **開關記在這個分頁**（`sessionStorage`）：換頁面板留著，對話不斷；重新載入也照舊開著。
- **桌面（`lg`，64rem 以上）並排**：整個外框變成兩欄——左邊是原本的頁首 + `main`（變窄），右邊是面板 `aside`，寬 `26rem`、`sticky top-0 h-dvh`、`border-l-2 border-rule-strong`、`bg-hull`。頁面照常可操作；各頁本來就以 `max-w-*` 與窄版規則排，變窄等於換到較窄的那一階。
- **窄版（`lg` 以下）全螢幕**：面板蓋滿整個視窗（`fixed inset-0`），底下那一頁 `inert`，面板是 `role="dialog" aria-modal`。這是這塊板子第一個疊層，只在窄版、而且蓋滿——沒有半透明遮罩、沒有陰影（The Rule-Line Rule 不變）。
- **焦點**：打開時落在輸入欄；`Esc`（焦點在面板裡）或「關閉」收起，焦點回到頁首那顆鍵。
- **不送頁面脈絡**：送出去的只有使用者打的字（票 11 的形狀）；助理要找作品就自己用搜尋工具。

## 面板結構（由上而下）

1. **抬頭列**（`deck`，`border-b-2 border-rule`）：`h2` `.label`「助理」、Ghost「新對話」（AI 開著才有）、Ghost「關閉」。
2. **對話紀錄**（可捲動，`role="log"`，串流中 `aria-busy`，答完才念）：
   - **你說的**：`.label text-ink-dim`「你」+ `deck` 底一塊散文（`text-sm`、`whitespace-pre-wrap break-words`）。
   - **助理說的**：`.label text-ink-dim`「助理」+ markdown 散文。markdown 只走白名單元素：段落、清單、粗斜體、行內 code（`.value`）、code block（`hull` 底 `.value text-xs`、`wrap-anywhere`）、表格（自己那一格 `overflow-x-auto`，不撐寬面板）、連結（`TEXT_LINK` 的底線、新分頁、`noopener noreferrer`）。標題降成 `.label`。原始 HTML 不渲染。
   - **圖片不載入**：markdown 圖片畫成一行 `.label`「圖片沒有載入」+ 替代文字 + `.value text-xs wrap-anywhere` 的網址原文（不是連結，不是 `<img>`）。理由：圖片網址是常見的外洩通道（brief §14、研究 C4 第 6 點）。
   - **工具呼叫一行**：`<details>`，`border-2 border-rule`、`well` 底。`summary` 是一顆按鈕：`.label`「工具」+ 人話名稱（「查為什麼沒入庫」「搜尋作品」「列出下載」「讀下載的時間線」，認不得的名字照原文 `.value`）+ 狀態：執行中是 `working` 小色塊「執行中」；完成是 `ink-dim` 字「完成」（常態不塗漆）；失敗是 `ink-dim` 字「沒成功」且框換 `rule-strong`（助理自己會看結果，不是阻擋，不塗紅）+ `ExpandHint`。展開沉一階到 `hull`：「參數」「結果」各一段 `.value text-xs whitespace-pre-wrap wrap-anywhere` 的 JSON。
   - **防護停下的說明**：這張票照票 11 當一般的助理文字顯示（後端寫的那句：哪一條、做到哪）。**之後的畫法**（票 22 接，等票 20 定下串流裡的停止資料）：不是模型說的、是 Berth 說的，畫成 `Notice` 的 `assigned` 色塊「停下」+ 那一句；`assigned` 而不是 `blocked`——這一輪已經結束，換個問法或再問一次就好，需要你決定下一步。串流與重新載入要是同一個形狀。
   - **空的對話**：一句散文說能問什麼與限制——「問 Berth 裡的事，例如『某部作品為什麼還沒入庫』。這個版本只會查，不會替你送單或改設定。」
3. **送出列**（`border-t-2 border-rule`，窄版加 `env(safe-area-inset-bottom)`）：`textarea`（`Field` 的外觀，2–6 行，`aria-label`「問助理」）；Enter 送出、Shift+Enter 換行、組字中（IME）的 Enter 不送。`PrimaryButton`「送出」（面板裡唯一的調度黃）；串流中換成 Ghost「停止」（關掉連線，後端留下「連線被關掉」那則說明）。

## 狀態與說法

| 狀態 | 畫面 |
| --- | --- |
| 讀取中（問 AI 有沒有開、接回對話） | 不動的 `deck` 色條佔位，沒有骨架動畫 |
| AI 沒開（admin） | 一句「AI 還沒設定。設好 provider 並打開之後，就能在這裡問 Berth 的事。」+ `GHOST_LINK`「到 AI 設定」（`/settings/ai`）；沒有送出列 |
| AI 沒開（user） | 一句「管理員還沒設定 AI。Berth 的其他功能照常可用。」；沒有連結、沒有送出列 |
| 送出時才發現 AI 關了（409 `ai_disabled`） | 重新問一次狀態，換成上面兩種 |
| 上一則還在答（409 `busy`，多半是另一個分頁） | `Notice` `assigned`「等一下」：「上一則還在回答（可能在另一個分頁）。答完再送。」字放回輸入欄 |
| 對話不見了（404，換了帳號或被清掉） | 開一段新對話，字放回輸入欄，一句說明 |
| 連不上 / 其他失敗 | `RequestFailed`（`blocked`「失敗」+「這一則沒送出去：」+ 原因）；字放回輸入欄（使用者按送出就是重試） |
| 串流中 | 「停止」；工具行「執行中」；字逐段出現 |

失敗的那一則使用者訊息從紀錄裡拿掉、字放回輸入欄：後端沒收下的東西不該留在畫面上，重新載入之後它也不會在。

## 後端的配合（這張票順手做）

- `GET /agent/status` → `{enabled}`：登入就能讀（一般使用者讀不到 `/settings/ai`），面板靠它分「沒開」與「可以問」。
- 停下的說明**不在這張改串流**（使用者 2026-10-27）：票 20 在另一個分支做斷路器狀態、繼續端點與串流裡的停止資料，兩邊同時改串流會撞。「停下」訊息塊的畫法記在票 22 的 Comments。

## 不做、留給之後

- 對話清單、切換舊對話（票面）；送頁面脈絡（使用者選定）；確認卡（票 13）；斜線指令（票 18）；每輪的步數與花費（票 21）。
- 不做浮動的聊天泡泡鍵、不做圓角氣泡、不做打字中的脈動點。

## 窄版與無障礙

- 390 寬沒有橫向捲動：機器字串 `wrap-anywhere`、散文 `break-words`、flex 子項 `min-w-0`；表格與 code block 只在自己那一格捲。
- 每個互動元件 ≥ 24px；焦點雙環照全域；狀態不只靠顏色（工具行的狀態都有字）。
