# 新 Feed 第一輪預覽的 shape（M3 票 11，2026-09-25）

`/impeccable shape` 的產出。三題照建議拍板（使用者同日）；其餘照 DESIGN.md 與 `rss-shape.md` 既有規則，不另開新語彙。

## 1. 工作與對象

- **誰、什麼時候**：admin 剛加了一個 Nyaa 或 acg.rip 的搜尋 feed，第一輪輪完（背景半分鐘內，或按「立即輪詢」）。
  搜尋 feed 一次帶著幾個月的歷史（acg.rip 30 筆、Nyaa 最多 75 筆），裡面夾著合集與別組的發佈。
- **要做的決定**：「全部下載」或「只追之後的」。選完之前這個 Feed 一筆都不送；選完寫 `primed_at`，這一塊消失。
- **成功**：一眼看得出「全部下載」會下什麼、哪些不會（排除、重複各為什麼），選一次就結束。

## 2. 版面（拍板：頁首獨立一段）

由上而下：**等你決定（新 Feed 的第一輪）** → 待綁定 → 排除條件 → Feed → RSS Series → 最近的 Feed Item。

- 段落標題 `.label` + 計數，旁邊 `assigned` 的「N 等你決定」色塊（Needs-You Floats Up，與待綁定同一個形狀）。
- 每個還沒選的 Feed 一塊（`article`，名稱是 Feed 名）：來源色塊（中性）+ 名稱、一句 lede
  「搜尋 feed 第一輪帶著歷史：選完之前一筆都不送」。
- **還沒讀過**（`last_polled_at` 是空的）：只有一句「第一輪還沒輪到：背景會在半分鐘內讀它，或在 Feed 段按『立即輪詢』」，
  沒有按鈕——沒看過的東西不讓人選「全部下載」。

## 3. 清單（拍板：摘要 + 依結果分組）

- 摘要一行等寬數字：「會送出 N · 綁定之後送 N · 排除 N · 重複 N」。
- **兩顆動作鍵緊接在摘要下面、清單在它們之下**（實跑時改：acg.rip 那一份「綁定之後送」有 22 筆，鍵放在清單後面的話 390 寬要捲好幾屏才按得到）。
- 四組，組內照發佈時間新的在前，每列：發佈名（`.value wrap-anywhere`）、發佈時間、大小（近似）：
  1. **會送出**（`matched`：它的 RSS Series 已綁好）——展開。
  2. **綁定之後送**（`unbound`）——展開；說一句「這些 Series 在上方待綁定段，綁好之後才送」。
  3. **排除**（`excluded`）——收起，每列說出哪一層的哪一條（沿用 `rss.skip.*`），合集在這裡。
  4. **重複**（`duplicate`，當場看的）——收起，每列說理由、連到那一筆下載。
- 空的組不出現。常態不塗漆：組名與列都是中性，只有段落標題旁那一塊是 `assigned`。

## 4. 動作

- **只追之後的**是主要動作（`assigned` 按鈕）：保守的那一邊（Product Principle 3）。當場再讀一次 feed；
  讀不到（502 `feed_unreachable`）時就地展開 `blocked` 的 Notice、說出原文，什麼都沒改。
- **全部下載**是 ghost 鍵、就地確認：確認區塊說出「會送出 N 筆，另外 N 筆綁定之後送；排除與重複的不送」。
- 選完那一塊消失：同一層 `aria-live`（段落裡常駐）說結果——「《名》：只追之後的，略過 N 筆」或
  「《名》：全部下載，送出 N 筆」；焦點照 `useFocusAfterRemoval` 落在下一塊或段落標題。
- 409 `feed_primed`（另一個分頁先選了）：重讀清單，那一塊自然消失。

## 5. 其他地方跟著改

- **Feed 段那一列**：還沒選時多一行中性字「第一輪還沒決定（見頁首）」。
- **最近的 Feed Item**：`passed` 是中性色塊「略過」，理由一句「新 Feed 選了只追之後的」。
- **Mikan 不走預覽**（拍板）：聚合 feed 只有最近幾集，加的那一刻就算選過；單一 feed 的整季由票 12 的補舊集處理。
- 窄版（390）同一順序、單欄，兩顆動作鍵各佔一整列。

## 6. 不做

預覽裡逐筆勾選（那是一次性 RSS 連結，票 18）、改過決定（選完就是選完；要重來就刪掉 Feed 再加一次）、
在預覽裡就地綁定（待綁定段已經有）。
