# Shape：設定頁的「通知」分頁（M4 票 123）

模式 **Operate**；全在既有的「泊位調度板」世界裡（DESIGN.md），不新增元件種類。使用者 2026-10-21 確認結構與訊息語言。

## 誰、何時、要做到什麼

- 精靈跑完之後的管理員，第一次接通知時在桌機上做一次：建好 Discord bot（Discord Developer Portal）、拿到 token，回來貼上、邀請 bot 進伺服器、填自己的 Discord ID、按測試、手機收到一則。之後只有換 token 或收不到時才回來。
- 成功的樣子：按「送一則測試訊息給我」之後畫面說「已送出」，手機上真的有一則私訊。失敗時當場說是哪一步、怎麼補，不必去 log 找。

## 結構（由上而下，`SettingsFrame` 單欄）

分頁列在 TMDB 之後加「通知」。它不是泊位：不上泊位號、不在泊位板上，分頁列與五格之間用一條細分隔（或間距）分開，讓人看得出那五格是一組。

1. **Discord bot**（`SettingsSection`，管理員一次性的設定）
   - 狀態一行（`dl`）：已設定時中性色塊「已設定」＋ bot 的名字（`.value`，Discord 回的 application 名）；沒設定是「還沒設定」。常態不塗漆。
   - Bot token：`PasswordField`＋「儲存」。存檔時 Berth 用它問 Discord 一次（`GET /applications/@me`），問得到才存，順手記下 application id 與名字。被拒（401）在欄位下就地說「Discord 不接受這個 token」；連不上說連不上，原文收進「技術細節」。存過之後欄位是空的，placeholder 說「已設定，貼上新的就換掉」；token 原文永遠不回到瀏覽器。
   - 邀請連結（設定了才有）：`.value` 的完整網址（`wrap-anywhere`）＋「複製」＋「開啟」（新分頁）。底下一句：bot 要和你在同一個伺服器，而且你在那個伺服器開著「私人訊息」。
   - 「移除 token」：Ghost，二次確認就地展開（移除之後通知停送）。
2. **我的 Discord**
   - Discord user ID：文字欄（`inputMode="numeric"`、`.value`）＋「儲存」。17–20 位數字，不合格在欄位下說。存檔時順手記下當下的介面語言，通知用那個語言寫（每人一個語言，使用者 2026-10-21 選）；畫面說一句「通知用目前的介面語言（中文）寫」，切語言後再按儲存就換。
   - 怎麼找 ID 一句：Discord 使用者設定 → 進階 → 開發者模式，然後右鍵自己的頭像 → 複製使用者 ID。
3. **測試**
   - 主鍵「送一則測試訊息給我」（這一頁唯一的調度黃；儲存鍵是 Ghost）。缺 token 或缺 ID 時 `aria-disabled`，`aria-describedby` 說缺哪一個。
   - 結果就地出現在鍵下（`aria-live`）：成功是 `secured` 色塊「已送出」＋「看看 Discord 的私訊」；失敗是 `blocked` 色塊＋一句人話＋補法＋收起的「技術細節」（Discord 的原文與代碼）。
   - 失敗種類與說法：token 被拒（換一個 token）；`50278`/`50007` 收件人到不了（兩個補法一起說：把 bot 加進同一個伺服器、在那個伺服器打開私人訊息——Discord 分不出是哪一種，brief §20.23）；限速（等幾秒再按）；Discord 連不上或 5xx（等一下再試）。

## 狀態

讀取中、讀取失敗（`RequestFailed`）；bot：未設定、已設定、儲存中、被拒、連不上、移除確認；ID：空、已存、不合格、儲存中；測試：停用（缺什麼）、送出中、成功、四種失敗。390 寬：`dl` 疊成一欄，鍵整寬。

## 不做、留給之後

- 票 124：Berth 對外網址一格（放在 bot 那一段之後）。票 125：通知種類勾選、一般使用者看得到「我的 Discord」與測試（bot 那一段只有管理員）。票 128：健康頁的通知卡、收件人層錯誤留在那個人的通知頁。
- 不做 webhook、不做頻道選擇、不在這頁教人建 Discord application（一句連到 Developer Portal 就好）。
