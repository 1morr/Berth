# Shape：不用 Prowlarr（M4 票 61）

2026-10-14，`/impeccable shape`。Visitor mode：Operate。視覺世界沿用泊位調度板（DESIGN.md），不新增元件語彙。

## 讀者與工作

拿掉 Prowlarr（或從沒接過）的管理員：只靠 RSS 追番，或暫時停掉 Prowlarr。要的是 Berth 不再把「沒有索引站」當成
壞掉：健康頁不紅、作品頁不露原始錯誤、隨時改得回來。

## 決定（使用者 2026-10-14 選定）

1. **狀態**：「不用 Prowlarr」與精靈頁 4 的「之後再說」是同一個狀態（`setup.indexer.skipped`，`skip_indexers`，
   `@command` 可逆）。
2. **設定 → Prowlarr，不用時整頁收成一塊**：一個 `Notice`（中性色塊「沒有使用」）說這代表什麼——健康不檢查它、作品頁的
   搜尋改說可以用 RSS、Berth 沒動 Prowlarr 上的站與容器——下面一顆「改回使用 Prowlarr」。健康卡、連線、站、介面登入
   都不畫。改回之後各區照常出現，健康那一項立刻重測。
3. **還在用時，頁尾一區「不用 Prowlarr」**：先說後果，按下去走就地確認（`useInPlaceConfirm` + `ConfirmPanel`），
   確認了才生效。不是紅色：它不是阻擋，也不是破壞性動作（可逆）。
4. **連線區的測試那一列帶測試時間**（「測試於 N 分鐘前」，`Timestamp`）。**之後的健康檢查連不上**（健康紀錄比測試新、
   而且是紅的）時，色塊換中性「過時」，結果列說「上次測試通過；之後的健康檢查連不上，見上面的健康卡」，給「重新測試」。
   不重複補法——補法在健康卡。

## 其他頁

- **健康頁 / 泊位板 BTH 4**：中性「沒有使用」（與「尚未接上」同色階、不同字），不算降級；卡片說明一句「你在設定 →
  Prowlarr 選了不用它」，附前往設定（admin）。
- **作品頁搜尋區**：`not_configured` 改說「沒有接索引站：可以接 Prowlarr，或用 RSS 訂閱」，色塊中性（使用者的選擇，
  不需要你）；兩個出口——設定 → Prowlarr（admin，非 admin 給請管理員那一句）與同頁的 RSS 訂閱區。
- **搜尋失敗**：人話那一句不變，服務回的原文收進「技術細節」（票 21 的分層），不再直接露出。

## 不做

- 不新增顏色意義；紅色只留給連不上的那種阻擋。
- 不移除 Prowlarr 上的站、不停容器：那是使用者的事（README 照舊說怎麼拿掉 profile）。
- 精靈頁 4 的「之後再說」外觀不動。
