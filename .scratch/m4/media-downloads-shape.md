# Shape：作品頁的「下載」段（M4 票 12）

`/impeccable shape`，2026-09-27。視覺世界沿用 DESIGN.md「泊位調度板」，不新開世界；版面契約是
`.scratch/m1.5/media-detail-shape.md` §3 的區塊序列，這一段往裡插一塊。使用者拍板三題（全數照推薦）：

1. **位置**：搜尋與 RSS 訂閱之後、季集與入庫之前。送完單往下一段就看得到它進去了；「在路上的」排在
   「已經在庫裡的」（季集、檔案）前面，照事情發生的方向。
2. **預設列哪些**：還沒了結的——`/jobs` 的「在路上」（還沒入庫也沒被移走，含需要人的），**加上已入庫而
   audit 還掛著的**（「N 個待確認」、第一批待確認）。它們也是在等人。其餘（已入庫而確認過的、移走的）
   在「全部」。
3. **季表的「下載中 / 卡住」連到 Job 詳情頁 `/jobs/:hash`**：一定到得了那一筆，不受這一段的篩選與分頁影響；
   一集被兩筆蓋到時連最新送的那一筆。

## 1. 工作與讀者

- **模式：Operate。** `admin` 與 `user` 都進得來（下載列表本來誰都看得到）。
- **時刻**：送完單、或 RSS 綁定之後回到作品頁，問「那幾個 torrent 呢」。2026-09-26 試跑：KAIJU GIRL CARAMELISE 的
  12 個 torrent 在 qBittorrent 排隊，作品頁的季表只標「下載中」、檔案與版本說「還沒有任何檔案入庫」——
  整頁像什麼都沒發生。
- **只有 Berth 說得出來的**：這個 torrent 是為了這部作品送的、裡面的每一個檔案 Plan 對到哪一季哪一集。
  qBittorrent 只知道前一半的一部分，Jellyfin 什麼都不知道。

## 2. 成果

- 看得到這部作品的每一筆 Job：名稱、狀態、進度、大小、來源（手動 / RSS 與字幕組）、Route、時間。
- 展開一列看檔案：檔名、大小、Plan 對到的季集（或處置：特典、略過、對不到）；一顆「Job 詳情」過去看時間線與動作。
- 進度即時動（SSE，沿用票 04 的合併失效）。

## 3. 選定方向

- **結構論點：提單上的「在途艙單」。** 季集是貨架上有什麼，這一段是還在海上的那幾艘船與它們的艙單（檔案）。
- **區塊序列**（`MediaDetailPage`）：身分帶 → 觀看 → 搜尋 → RSS 訂閱 → **下載** → 季集與入庫 → 檔案與版本 → TMDB。
- **一列＝下載列表的一列**，同一種 `<details>` 船期列、同一個狀態色塊、同一個 `AuditChip`、同一行 `JobFacts`；
  差別只有兩處：
  1. 事實行不重印作品名（整頁都是這部作品），換成來源那一格說字幕組（RSS）。
  2. **展開區是檔案清單，不是時間線**：這一頁問的是「裡面有什麼、對到哪幾集」；時間線與動作在 `/jobs/:hash`。
- **焦點時刻**：區塊標題列的兩顆篩選鍵上的數字——「還沒了結 12」一眼說出有幾艘在路上。

## 4. 範圍與邊界

- **後端**
  - `GET /jobs?media=<id>`：與 `filter`、`page` 並用；件數（`counts`）照這部作品算。
  - `JobFilter` 多一組 **`open`**（還沒了結＝在路上 + 已入庫而 audit 還掛著），只有這一段用；`/jobs` 的篩選列不變。
  - `GET /jobs/{hash}/files`：`job_files` 逐檔（相對路徑、大小、要不要下載），加上這一筆現在那一份 Plan 對這個檔案的
    處置與季集。qBittorrent 還沒給檔案清單時是空陣列。
  - `JobOut.series`：RSS 送的那一筆的字幕組（發佈名讀出的；讀不出是 Series 的原始標題），不是 RSS 是空字串。
  - `EpisodeOut.job`：季表上「下載中 / 卡住」那一集是哪一筆（最新送的那一筆），其餘 `null`。
- **前端**：`media/DownloadsPanel.tsx`（新）、`SeasonList` 的狀態格變連結、`MediaDetailPage` 插一塊並掛 `useJobStream`。
- **不做**：在這一段按重試、刪除、重新規劃（動作在 Job 詳情頁，票 M2 12 的理由：兩處各畫一份會各長各的）；
  時間線；依 Route / trigger 篩；把頁碼寫進網址（作品頁的網址不為一段清單加參數）。
- **不碰**：`/jobs` 的篩選、季表的判定與欄序、檔案與版本、搜尋區塊。`/jobs` 的列與這一段是同一個 `JobSummary`，
  所以那裡的事實行也多了字幕組（build 時定：同一格資料在兩處說法不同才是錯）。
- **反目標**：不在列上疊檔案數以外的彙總（「12 集 · 3.4 GB」那種整段總和）；不做進度條以外的新視覺（沒有進度條——
  下載列表本來就是 `progressInline` 的一格字）。

## 5. 狀態與範圍值

| 狀態 | 樣子 |
| --- | --- |
| 這部作品從沒送過任何下載 | **整段不畫**（探索點進來的新作品不多一塊空殼） |
| 讀取中 | 不畫（同觀看區：晚一點出現比先畫格子好） |
| 後端問不到 | 一行 `ink-dim` + Ghost「重試」 |
| 還沒了結的是 0、全部有 N | 一句「這部作品沒有還在路上或等你確認的下載。」，「全部 N」那顆照常可按 |
| 1–50 筆 | 一列一筆，最新在前 |
| 超過 50 筆（RSS 補舊集多版本） | 共用 `Pager`，上方一組、清單底一組（有別頁才畫）；鍵是按鈕、頁碼不進網址 |
| 展開：檔案讀取中 | 一行「正在讀檔案清單」 |
| 展開：qBittorrent 還沒給檔案清單（磁力、排隊中） | 一句「qBittorrent 還沒給出這個 torrent 的檔案清單。」 |
| 展開：有檔案、還沒有 Plan | 檔名與大小，季集那一格 `—` |
| 展開：不下載的檔案（priority 0） | 照列、季集那一格說「不下載」 |
| 展開：上百個檔案（BD 整季 + 字幕 + 字型） | 整份照列（展開是使用者要的）；一列一行，窄版檔名換行不截斷 |

季表：`下載中`、`卡住` 兩種帶 `job` 時是連到 `/jobs/:hash` 的連結（原本 `卡住` 連 `/jobs`）；沒有 `job` 時（理論上不會）
照舊是字。

## 6. 互動與版面

- **標題列**：`h2`「下載」+ 右邊兩顆篩選鍵（`FILTER` / `FILTER_ACTIVE`，選中的是 `aria-current` 的字），
  「還沒了結 N」「全部 N」。換篩選回到第 1 頁。
- **列**：`<details>`，摘要是狀態色塊、待確認色塊、展開提示、發佈名（整行換行）、事實行
  （來源 · Route · 大小 · 進度 · 時間 · hash）。展開區：檔案清單（`ul`，每列 檔名 `.value wrap-anywhere` +
  右側 季集 / 處置 · 大小），底下 Ghost「Job 詳情」。
- **Tab 順序**：篩選鍵 → 分頁 → 每一列的 summary →（展開時）Job 詳情。
- **即時**：`useJobStream` 掛在這一段上（有 Job 才掛）；key 在 `['jobs', 'list', ...]` 與 `['jobs', hash, 'files']`，
  所以票 04 的合併失效自動涵蓋：推播到的那一筆的檔案清單跟著重問（Plan 算出來時季集才會出現）。
- **窄版**：390px 無頁面層級橫向捲動；檔案列的季集與大小換到檔名下一行。

## 6.1 build 時定的

- **檔案列說季集，也說處置**：pre-plan 停在待審的那一份也有提案的季集（演練情境 `downloads` 的 `- 25`），
  只印「待審」會把「它以為是 S01E25」藏起來，所以是「S01E25 · 待審」；正片只印季集。
- **只有一頁時不畫分頁**：一行「1–3 / 3」在這一段只是雜訊，篩選鍵上已經有數字。
- **「連最新送的那一筆」是同一種標籤之內**：一集同時被一筆卡住的與一筆下載中的蓋到時，標籤說「卡住」
  （`EpisodeStatus` 的優先序），連的也是卡住的那一筆——說的與連到的要是同一件事（code-review 問過）。
- **季表跟隨也看計劃出現**（`plan_id`）：下載中的 pre-plan 不改 Job 狀態，只看狀態的話季表要等 5 分鐘
  才說「下載中」（code-review 抓到）。
- **翻過最後一頁**與「還沒了結的是 0」分開說：前者照 `/jobs` 給回第一頁的路。
- **`key` 不能與季表的 `key` 相同**：兩者是同一層兄弟，撞 key 時 React 會重掛這一段、多送一次請求（vitest 抓到）。

## 7. 約束

- **狀態分組的規則只有一份**：`open` 的狀態集合在 `services/jobs.py` 旁邊的 `FILTER_STATES`，audit 那一半與
  `_plans_of` 數的是同一個欄位（`plan_items.audit`）。
- i18n：文案走 key，zh-Hant 與 en 並列；檔名、發佈名、字幕組、Route 名不是文案。
- The One Meaning Rule：這一段只有 Job 狀態那一格塗漆；處置與季集是中性的字。
- **季表跟著這一段換狀態**：`GET /media/{id}` 的季表 `staleTime` 5 分鐘、SSE 不讓它失效（2026-09-26 審查記過）。
  這一段把「下載中」連到那一筆之後，兩塊並排說相反的話就藏不住了：這一段看到**任何一列的狀態變了**時讓
  `['media', id]` 失效一次（進度變不算）。不改 SSE 本身的規則。
