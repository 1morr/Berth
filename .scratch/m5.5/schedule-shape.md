# 時間表 shape（M5.5 票 09）

2026-11-04。使用者確認兩件事：最小版**全部列、不篩**（長壽 / 兒童節目與國產動畫都留著，篩不篩等用過再定）；
卡片是**小海報橫列**，不是探索牆那種 2:3 直卡。其餘照 `DESIGN.md` 的既有方塊與 AutoBangumi Calendar（brief §20.3）。

## 誰、在什麼時候

- 任何登入的人，季初與每週想「這週有什麼新番、我追的今天出了沒」時打開。Operate 模式：掃一欄、認出一部、點進去。
- 成功：認出想看的那一部，點進 `/media/:id` 用現有的訂閱流程訂下去；下一次打開那張卡說「已訂閱」。
- 一週約 160 部（票 08 實測 164），一天 15–30 部；空的一天可能出現（TMDB 沒建集、季初）。

## 結構

```
桌機（≥ lg）
[時間表] [訂閱 1]                                  ← 區塊分頁列（訂閱只有 admin）
時間表   11/02 – 11/08                [只看已訂閱]
週一 11/02 │ 週二 11/03 今天 │ 週三 │ … │ 週日
┌──┬────────┐
│▓▓│藥師少女的…│   一部一列：小海報、顯示用標題（兩行）、S02E05、狀態色塊
│▓▓│S02E05    │
│  │[已訂閱]   │
└──┴────────┘

窄版（< lg）
[時間表] [訂閱 1]
時間表   11/02 – 11/08
[只看已訂閱]
[一][二 今天][三][四][五][六][日]   ← 選一天，預設今天
週二 11/03 · 今天 · 18 部
┌──┬──────────────┐
│▓▓│…              │
└──┴──────────────┘
```

- **分頁列**：`AiringTabs` 多「時間表」在最前面（每個人），「訂閱」只給 admin。頁首「新番」對每個人顯示、連 `/schedule`；
  件數（待綁定）仍只有 admin 看得到。
- **抬頭**：`<h1>` 時間表，旁邊 `.value` 寫這一週的日期範圍。右側（窄版下一行）一顆切換「只看已訂閱」（`ToggleChips` 單顆，`aria-pressed`）。
- **桌機七欄**：週一到週日，每欄一個 `<section>`，標題 `<h2>`「週二 11/03」加件數；今天那一欄標題後面一塊 `working`
  小色塊「今天」，欄頂一條 `inset` 重橫線（文字＋形狀，不只靠顏色），`aria-current="date"`。欄內是 `<ul>`。
- **窄版單日**：七顆日期鍵（`ToggleChips` 外觀，單選、`aria-pressed`），預設今天；下面只畫那一天的清單。
  換天不換網址（最小版不記）。
- **卡片**（一部一個 `<li>`）：整列一條連結到 `/media/tv:<id>`，名字是作品名（`aria-label`），集數與狀態是
  `aria-describedby`。左邊 `w-12` 的 2:3 小海報（`alt=""`，沒有就畫 `TilePlaceholder` 的縮小版），右邊：
  標題（`.value text-sm line-clamp-2`）、`S02E05`（`.value text-xs text-ink-dim`）、狀態色塊。框同牆卡片：
  `border-2 border-rule`，hover / focus 換 `rule-strong`。
- **狀態**（每次照資料庫算，不進快取）：
  - 未訂閱：**不畫色塊**（The Usual Stays Unpainted Rule：大多數卡片都是它）。
  - 已訂閱：中性小色塊（`deck` + `ink`）。作品現在有一條訂閱（`CONTEXT.md`〈訂閱〉；code-review 後改，原寫「有綁好的 RSS Series」）。
  - 已入庫：中性小色塊。卡片上那一集在帳本裡。蓋過「已訂閱」。
  - 「晚 N 天」是票 12 的層，這一票不畫。
- **一般使用者**：看到同樣的卡片與狀態；不顯示字幕組、Feed（API 也不送）。
- **排序**：一天之內已入庫與已訂閱的在前，其餘照 TMDB discover 的順序（熱門度）。
- **歸屬**：頁尾 `TmdbAttribution`（TMDB 條款，PRODUCT.md〈Evidence on Hand〉）。

## 狀態

- 讀取中：七欄（窄版一欄）各畫幾格同尺寸的空位格，不跳版。
- TMDB 沒設憑證或連不上：`TmdbNotice`（同探索頁），可重試；第一次抓約 5–10 秒，抬頭下一行說「第一次打開要抓一陣子」。
- 只看已訂閱而一部都沒有：一句話加一條連到探索頁的連結（訂閱從作品頁開始）。
- 某一天沒有：欄裡一行 `ink-dim`「這天沒有」，欄不收掉（七欄對齊）。

## 不做的（這一票）

- 換週、未知播出日那一欄（AutoBangumi 有「未知」：discover 的每一部都有 TMDB 的播出日，對不出就不列）。
- 時刻與評分（票 14）、晚 N 天（票 12）、篩長壽節目與國產動畫（等用過再定，記在票的 Comments）。

## 驗收怎麼看

- e2e（桌機、390px）：未訂閱的卡片點進作品頁訂閱，回到時間表那張卡說「已訂閱」。
- e2e：一般使用者看得到時間表與狀態，分頁列沒有「訂閱」。
- vitest：今天那一欄標出；窄版換天；只看已訂閱。
