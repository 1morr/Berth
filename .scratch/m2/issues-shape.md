# `/issues` 形狀（M2 票 05，`/impeccable shape`）

2026-09-22。視覺世界沿用 DESIGN.md 的「泊位調度板」，這一份不開新世界——它是同一塊板上
多出來的一頁，模式是 **Operate**（使用者是來把一件事處理掉的，不是來看的）。

## 這一頁的工作

**誰來**：admin，而且是被一件壞掉的事叫來的——Jellyfin 裡刪了一部片、硬碟搬過家、
qBittorrent 掉了一個 torrent。他不是整天盯著 Berth 的人（`PRODUCT.md`「人只在『想找新片』
與『有東西壞了』兩種時刻打開它」）。

**他要做的一件事**：對每一件 Issue 做一個決定，然後讓它從清單上消失。所以成功的樣子是
**空清單**——這一頁最好的狀態是沒有東西。

**這裡獨有的真話**：Berth 的帳本知道每一個媒體庫檔案來自哪個 torrent，所以它說得出
「這個檔案不見了，而它的來源還在 complete，按一下就回來」。這是 \*arr 生態沒有的那一句。

## 排法

**一列一件事**，與票 06 的 `/review` 同一個排法但**兩份元件**（使用者 2026-09-22 拍板）：
這一票只做 `IssueRow`，票 06 做 `/review` 時手上有兩個真實案例，再把共用的那一列抽成
`QueueRow`。用一個案例猜介面會猜錯。

一列由上到下三段，全部在 `row-summary` 的框裡：

1. **識別**：那一條路徑的檔名（`.value`，完整路徑在展開區）。左邊一個 `chip-blocked` 的型別
   標籤——`library_link_missing` 是「阻擋」：在人動手之前它不會自己好。
2. **一句話**：這一件是什麼（i18n 逐型別一句，不是 `detail_json` 的傾印）。
3. **動作**：照後端算好的 `actions` 順序畫，第一顆是 brief §9.1 的預設建議動作。
   `actions` 是空的那一列只有「忽略」。

展開區（`row-expanded`，沿用 `CollapsibleRow` 的 `<details>`）放完整路徑、來源路徑、
季集與偵測時間——掃視時不該被路徑淹沒，但要修的時候需要它們。

## 對帳的控制項

**頁首橫幅**（使用者拍板）：標題列右側一顆「立刻對帳」，按下之後**同一條橫幅**就地展開四方的
進度，不跳頁也不開面板。

- 跑完收成一行摘要：上一輪什麼時候、開了幾件、更新了幾件。
- **問不到的那一方用文字說出來**，不是安靜地少一列（brief §16.2）：畫面要分得出「都好好的」
  與「根本沒比」。四方各一列，`counted` 用 `.value tabular-nums`。
- 跑的時候輪詢 `GET /reconcile`；正在跑時那顆按鈕是 `aria-disabled` 而不是 `disabled`
  （M1.5 票 05 的教訓：停用的鍵接不住送回來的焦點）。

## 破壞性動作

「連 complete 一起刪」的單位是**整筆下載**，不是那一個檔案——來源是一個 torrent，抽掉其中
一個檔案只會讓 qBittorrent 再抓回來（brief §9.2）。所以：

**就地確認**（使用者拍板），沿用 `ConfirmAction`：在那一列裡展開一段散文說「這會移除這一筆
下載的全部：媒體庫鏈接、torrent、complete 檔案與紀錄」，再按一次才執行。**不重用票 04 的
四旗標對話框**——那四個旗標是這一顆自己寫死的（四個全勾），給了勾選框反而像它們可以改。

另外兩顆不確認：重新鏈接是還原，承認刪除只動帳本一列，兩個都不碰使用者的檔案。

## 狀態與範圍

| 狀態 | 畫面 |
| --- | --- |
| 讀取中 | 兩列靜態佔位（同 `JobsPage` 的 `Loading()`，這個世界沒有骨架屏動畫） |
| 空 | 「沒有要決定的事」＋一句「上一次對帳是什麼時候」＋那顆按鈕 |
| 一般 | 1–20 列。典型是 1–3 件（一次手滑刪除） |
| 多 | 一次掛載掉了會是整個媒體庫。**不分頁**（同 `GET /review` 的決定）——那時候該修的是掛載 |
| 動作失敗 | 那一列**留著 open**，就地顯示 `reason` 對應的句子與 `detail` 原文（`relink_failed` 的原文是 errno 與哪兩個掛載，plan §8.6） |

## 邊界

- **不碰**：健康頁（唯讀診斷，issues 要按動作，決定 3 已經分開了）、`/jobs`、票 06 的 `/review`。
- **不做**：篩選、排序、分頁、批次選取。這一票只有一種型別，清單短；批次是票 09 有了十一種
  之後才回答得了的問題。
- **不做**：已決定過的歷史檢視。`GET /issues` 只回 `open`（工作清單不是歷史）。

## 約束

- 文案全走 i18n key，zh-Hant 與 en 並列；`count` 要 `_one` / `_other`。
- 型別標籤與動作名是**封閉集合**，從 OpenAPI 產的型別取（`Schemas['IssueOut']`），前端不抄一份。
- WCAG 2.2 AA：純鍵盤走得完（確認區收起時焦點送回那一顆按鈕）、狀態不只靠顏色
  （色塊＋模板字標籤，The Triple Encoding Rule）。
- 導覽列的入口只有 admin 看得到；後端同時回 403（前端隱藏不是安全機制）。
