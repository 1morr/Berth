# Shape：繼續觀看與下一集——首頁 `/` 與媒體庫頁上方的兩列（M1.5 票 07）

`/impeccable shape`，2026-09-17。視覺世界沿用 DESIGN.md「泊位調度板」，不新開世界。首頁的其餘部分照
`.scratch/m1/discover-shape.md`，媒體庫頁照 `.scratch/m1.5/library-shape.md`（它的 §4 已替這兩列留了位置）。

使用者拍板三件事（2026-09-17，全數照推薦）：

1. **一行放不下時收起、就地展開**：收起時每一列只佔一行（欄數與牆同一份 `WALL_GRID`：窄版 2、`sm` 3、`lg` 4、`xl` 6），
   多的藏起來，一顆「全部 N 項」就地展開成多行、再按收起。不做橫向捲動列。
2. **媒體庫頁只在第 1 頁、沒有篩選時畫**（「待審」「Unmatched」、類型、年份都算篩選；排序不算）。
3. **Jellyfin 連不上時首頁說一行 + 重試**，不用紅色 Notice；媒體庫頁不另外說（牆自己的錯誤那一塊已經說了）。

## 1. 工作與讀者

- **模式：Operate。** `admin` 與 `user` 都看得到，內容是**這個人自己**在 Jellyfin 的紀錄。
- **時刻：「接著看」。** 打開 Berth 的人有一部分不是來找新片，是想接上昨晚看到一半的那一集。以前他得開 Jellyfin；
  現在首頁第一眼就有，點下去落在 Jellyfin 的那一集（Jellyfin 沒有直接開始播放的網址，研究 §8）。

## 2. 成果與證據

- **主要任務**：認出要接著看的那一集，點下去。
- **真實資料**：Jellyfin `GET /UserItems/Resume`（看到一半的集與電影，`mediaTypes=Video`）與 `GET /Shows/NextUp`
  （每部看過的劇的下一集）。多數人 0–5 項繼續觀看、0–20 項下一集；一個剛裝好的 Berth 兩列都是空的。
- **只有 Berth 說得出來的**：沒有。這兩列是 Jellyfin 的資料原樣搬過來；價值在「不必開另一個介面」（PRODUCT 原則 1）。
  所以它們**不疊 Berth 的入庫狀態**、不塗漆。
- **名稱**：作品名與集名都是 Jellyfin 的（與媒體庫牆上在 Jellyfin 裡的作品同一條規則，brief §7.5），不跟 UI 語言。

## 3. 選定方向

- **視覺權威**：DESIGN.md。卡片是貨櫃的另一種擺法：**橫放的貨櫃**——16:9 的圖是塗裝，下方同一條標識帶。
  與下面的牆共用 `WALL_GRID`，格線上下對得齊；框是每一格自己的 `border-2`。
- **結構論點：碼頭邊正在卸的那幾箱。** 兩列是「已經卸到一半」的貨，擺在堆場全景之前；一行擺得下的就是一行，
  多的收在同一個位置，不推到畫面外。
- **頁面序列**
  - 首頁：`h1`（`sr-only`）→ **繼續觀看** → **下一集** → 搜尋列 → 趨勢 / 熱門（或搜尋結果）→ TMDB 標示。
    兩列在搜尋列**上方**而且搜尋時不收起：收起的話，打字時輸入框會往上跳。
  - 媒體庫頁：抬頭 → 切換列 → **這個媒體庫的繼續觀看** → **下一集** →「還沒進 Jellyfin」帶 → 篩選列與分頁 → 牆。
- **每一列**：`.label` 標題 + `.value` 計數壓在重橫線上（DESIGN.md 區塊標題）；有藏起來的格子時標題列右邊一顆
  「全部 N 項 / 收起」（`aria-expanded`、`aria-controls` 指向那份清單）。**開關放在標題列而不是清單下方**
  （拍板時的預覽畫在下方）：展開之後下一個 Tab 從第一格開始往下走，新出現的格子不會落在焦點的後面。
- **焦點時刻**：沒有。整列是中性的，圖自己有顏色；四個信號色一個都不出現。

## 4. 範圍與邊界

- **範圍**：兩個頁面上方的兩列；一種橫卡；後端兩支（整個帳號、單一媒體庫）與它們的權限閘門；代理圖片多開
  `Thumb`、`Backdrop` 兩種類型與一個 16:9 的尺寸。
- **不做**：在 Berth 裡播放、「從頭播放 / 繼續播放」的選擇、隱藏某一部的下一集、`最新加入` 那一列、
  Jellyfin 的使用者設定（`maxDaysForNextUp`、`enableRewatching`）、觀看區（票 08）。
- **不碰**：探索牆與搜尋、媒體庫的牆與篩選、設計 token。
- **反目標**
  - 不做橫向捲動列（The Board Never Scrolls Rule 的同一個理由）。
  - 不在圖上疊進度條、色塊或文字（The Paint Needs A Painted Ground Rule）；進度是標識帶上的一行字。
  - 不為這兩列畫讀取中的空位格：它們多數時候是空的，先畫格子再整列消失比晚一點出現更跳。
    **（M2 票 13 推翻：首頁量到 CLS 0.35。改成照這個人上一次的形狀佔位，第一次來仍不畫；見 progress.md 偏差。）**
  - 不疊 Berth 的入庫狀態：這一列的每一格都已經在 Jellyfin 裡，而且狀態屬於作品、不屬於某一集。

## 5. 狀態與範圍值

### 列

| 狀態 | 樣子 |
| --- | --- |
| 讀取中 | ~~不畫（不留空位格）~~ 照上一次的形狀佔位，第一次來不畫（M2 票 13） |
| 沒有內容 | 那一列整個不畫，不留標題 |
| 一行放得下 | 沒有「全部 N 項」鍵（在那個寬度下 `display: none`，不進無障礙樹） |
| 一行放不下 | 收起時藏掉多的；「全部 N 項」展開、「收起」收回；換頁面不記住 |
| Jellyfin 連不上（首頁） | 兩列的位置換成一行 `ink-dim` 字「問不到 Jellyfin，繼續觀看與下一集暫時看不到」+ 服務原文（`.value text-xs wrap-anywhere`）+ Ghost「重試」 |
| Jellyfin 連不上（媒體庫頁） | 不畫；牆那一塊已經說了 |
| 帳號在 Jellyfin 被停用 | 後端結束 session、回 401；前端重跑路由守衛，落到登入頁（與媒體庫頁同一條路） |
| 網址上的媒體庫不在允許清單 | 不畫；牆那一塊說「找不到這個媒體庫」 |
| 後端不可達 | 首頁不畫（探索牆自己說）；媒體庫頁不畫 |

### 卡片

| 行 | 內容 |
| --- | --- |

## 6. 互動與版面

- **寬度**：跟著所在的頁（兩頁都是 `max-w-[110rem]`）。
- **收起的做法**：每一格自己帶「在哪個斷點以上才出現」（第 3 格 `sm`、第 4 格 `lg`、第 5–6 格 `xl`、第 7 格起永遠藏），
  「全部 N 項」在放得下的斷點以上不畫。一份 DOM，不量寬度。
- **Tab 順序**：標題列的開關 → 每一格。卡片的焦點環是全域雙環；hover / focus 時框換 `rule-strong`。
- **標題層級**：兩列各是一個 `section`，`aria-labelledby` 接 `h2`；卡片的作品名不是標題（整格是連結，連結名就是
  作品名 + 季集 + 集名 + 進度）。
- **窄版**：兩欄，標識帶的每一行照樣截斷，不橫向捲動。

## 7. 約束與不可自行發明的決定

- **權限**（plan §11.2b、研究 §2）：首頁那兩支**不帶** `parentId` / `seriesId`（Jellyfin 才照使用者的媒體庫限縮）；
  媒體庫頁的媒體庫 id 先對允許清單驗過才變成 `parentId`，不在清單就 404 且不問 Jellyfin；`userId` 只從 session 來。
- **Resume 一定帶 `mediaTypes=Video`**（研究 §1.2：不帶會混進 Season 與 Series）。
- **深連結**：`#/details?id=<那一集>`，主機照 `services/deeplink.py`（票 13）。
- **i18n**：文案走 key，zh-Hant 與 en 並列。作品名、集名、季集代號、服務原文不是文案。
- **無障礙**：深淺兩主題文字 ≥ 4.5:1；390px 無頁面層級橫向捲動；開關 ≥ 24×24；外部連結說得出會開新分頁。
- **不可發明**：取圖順序、Resume / NextUp 的參數（照 jellyfin-web，研究 §7）、觀看進度的判定（`services/watch.py`）。
