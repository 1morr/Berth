# Shape：長清單收合——季表、檔案與版本、下載列的計劃（M1.5 票 09）

`/impeccable shape`，2026-09-18。視覺世界沿用 DESIGN.md「泊位調度板」，不新開世界。版位照
`.scratch/m1.5/media-detail-shape.md` §4 留給票 09 的位置填（「季集與入庫」的工具列與各季、「檔案與版本」），
`/jobs` 那一半照 `.scratch/m1/jobs-shape.md` 的展開區，不重排任何一頁。

使用者拍板三件事（2026-09-18，全數照推薦）：

1. **檔案與計劃依決定分組**：一組是「同一季 × 同一處置」（計劃再分信心與待確認），一組一行；需要人的組排最前、
   左線加重；展開一組才逐檔列出，逐檔那一列沿用現在的樣子。兩份清單共用這一種收合。
2. **「只看缺集」只算「缺」**：已播出、沒有任何下載在處理的集。卡住、下載中、未播出都不算。
3. **展開的一段，摘要列黏在畫面頂端，底端另有一行「收起」**：捲到哪裡都收得起來。

採用的慣例：摘要列黏頂照 GitHub PR「Files changed」的檔案標頭（捲到那個檔案的任何位置都按得到收合）；
依決定分組照這個 repo 自己的時間線「鏈接了 N 個檔案」合併列（DESIGN.md 下載列一節）。另一條路——Sonarr
Interactive Import / qBittorrent 內容分頁那種逐檔一行的緊湊表——芙莉蓮仍是 39 行，沒選。

## 1. 工作與讀者

- **模式：Operate。** 季表是「缺什麼」、檔案是「媒體庫裡實際上有什麼」、計劃是「這包檔案會被寫到哪裡」。三個時刻都是
  **先要一個總數與例外**，逐集、逐檔是要查證時才看的。
- 讀者手上的真實資料（票 15 critique、2026-09-18 以 benchmark 語料重算）：
  - 名偵探柯南：TMDB 併成一季 1213 集。收起時仍渲染整張表，開頁就多幾千個節點。
  - 葬送的芙莉蓮 `[7³ACG]` BD 合集：39 個檔案，S01 28 個高信心、S00 11 個中信心（待確認）；逐檔一列 4–6 行，
    計劃展開 9,000 px 以上。

## 2. 成果與證據

- 季表：收起的季**不渲染**集列；展開的一季不必捲回頂端就能收起；可以只看缺集，每季說得出「缺 N 集 / 沒有缺集」。
- 檔案與計劃：預設看到的是**組**（一行），不是檔案；需要人的組不必展開就看得到（The Needs-You Floats Up Rule）；
  逐檔資訊（目標路徑、帳本、Jellyfin、理由）展開那一組仍然全部拿得到。

## 3. 選定方向

- **結構論點：貨單先寫櫃數，不先列每一箱。** 一組是一個貨櫃：外面漆著它裝了什麼（處置 · 季 · 集數範圍 · 箱數 · 狀況），
  打開才一箱一箱點。
- **一種可展開的段落，三處共用**（季、檔案組、計劃組）：原生 `<details>`；**收起時不渲染內容**；展開時摘要列
  `sticky top-0` 貼在畫面頂端（`well` 底，底下一條 `border-b-2 border-rule`，內容在它底下捲過去）；內容最後一行是
  Ghost 小一號按鈕「收起 S01」。收起之後那一段的摘要列若在畫面外就捲回來；從底端的鍵收起時焦點落在摘要列上。
- **焦點時刻**：需要人的那一組。左線 `rule-strong`，排在最前面；不塗漆（處置與信心是分類，The One Meaning Rule）。

## 4. 範圍與邊界

- **範圍**：`SeasonList`（工具列、只看缺集、各季的摘要與收起）、`FilesPanel`（劇集的檔案依組分）、`JobPlan`（依組分）。
- **不碰**：季表的判定與欄序、帳本與計劃的內容、多版本並存與對不到的檔案兩塊、時間線、電影的檔案（一兩個，照舊不分組）、
  觀看區、搜尋。
- **留給票 10**：工具列的「搜這部作品缺的集」與展開區第一行的「搜這一季缺的集」（media-detail-shape §4）。
- **反目標**：不虛擬捲動 1213 列（展開一季就是要看那一季，收起不渲染已經解掉開頁的代價）；不把「只看缺集」寫進網址；
  不在收起狀態下自動展開有缺集的季（1213 集的季自動展開就是原來的問題）；不為組塗信號色。

## 5. 狀態與範圍值

### 季表工具列（「季集與入庫」標題列下方）

| 狀態 | 樣子 |
| --- | --- |
| 劇集、至少一季 | 一顆 `NAV_BOX` 切換鍵「只看缺集」（`aria-pressed`，選中重線 + `deck` 底）|
| 開啟 | 切換鍵旁一行 `.value text-xs`：「共缺 N 集」/「這部作品沒有缺集」（`aria-live="polite"`）|
| 電影、沒有任何一季 | 工具列不畫、不留高度 |

### 一季（`SeasonList` 的一列）

| 狀態 | 樣子 |
| --- | --- |
| 收起 | 摘要照舊（代號、季名、集數、入庫 / 播出、播出日、展開）；**沒有集表的 DOM** |
| 只看缺集開啟 | 摘要多一格：「缺 N 集」（`.value text-xs text-ink`）或「沒有缺集」（`text-ink-dim`）。展開 / 收起不因切換而變 |
| 展開 | 摘要黏頂；集表；最後一行「收起 S01」|
| 展開 + 只看缺集 | 集表只留「缺」那幾列；沒有就一句「這一季沒有缺集」取代集表 |
| TMDB 沒有這一季的集 | 照舊一句 `media.season.empty` |

### 一組（檔案與版本 / 計劃）

| | 檔案與版本（劇集） | 計劃 |
| --- | --- | --- |
| 分組鍵 | 處置 × 季 | 處置 × 季 × 信心 × 待確認 |
| 摘要 | 處置中性小色塊 · `S01 E01–E28` · N 個檔案 · 帳本 · Jellyfin | 處置中性小色塊 · 信心 · 待確認 · `S01 E01–E28` · N 個檔案 |
| 需要人（排前、左線 `rule-strong`） | 帳本不是 `ok` 的、Jellyfin 找不到的 | 待審、對不到、待確認 |
| 帳本那一格 | 全部 `ok` 是「帳本對得上」，否則「N 個帳本對不上」| — |
| Jellyfin 那一格 | 只算正片：「Jellyfin 已收錄 N」「還在掃描 N」「N 個找不到」，是 0 的不說；字幕與特典沒有這一格 | — |
| 集數範圍 | 連續的寫成 `E01–E28`，斷開的逗號分開（`E01–E05, E07`），多集檔算它蓋到的每一集；沒有季集的組（略過、對不到）不寫 | 同左 |
| 展開 | 逐檔列（現在的 `FileRow` / `PlanRow`）+ 最後一行「收起」| 同左 |

集數範圍用 en dash 並與季代號之間空一格（`S01 E01–E28`），不寫成 `S01E01-E28`——那是 Jellyfin 的多集檔寫法，
會被讀成一個檔案。

## 6. 互動與版面

- **鍵盤**：摘要列是一顆按鈕（Enter / Space）；Tab 順序＝工具列切換鍵 → 各季摘要 → 展開那一季裡的連結（卡住）→ 「收起」→
  下一季。從底端「收起」之後焦點在那一季的摘要列上，下一個 Tab 是下一季。
- **黏頂遮住焦點**（WCAG 2.2 2.4.11）：展開區裡的連結與按鈕帶 `scroll-margin-top`，反向 Tab 捲回去時不會躲在摘要列底下。
- **窄版**：摘要列照舊換行（季名自己一行）；黏頂時窄版頂端約佔 90px，是拍板時知道的代價。
- **Find in page**：收起的段落不渲染，瀏覽器的頁內搜尋找不到收起的集名與路徑（原生 `<details>` 找得到並會自己展開）。
  這是「收起時不渲染」的代價，拍板的方向不變。

## 7. 約束與不可自行發明的決定

- 「缺」就是 `EpisodeStatus.MISSING`（後端判定），前端只數它，不重新判定。
- 處置、信心、帳本與 Jellyfin 的字眼沿用既有的 i18n 值；新文案 zh-Hant 與 en 並列。
- 季集代號走 `components/episodes.ts`（The Machine String Rule：不翻譯、不大寫轉換）。
- 深淺兩主題文字 ≥ 4.5:1；390px 無頁面層級橫向捲動；切換鍵與「收起」≥ 24×24。
